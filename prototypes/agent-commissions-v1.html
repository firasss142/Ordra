Prototype — commissions agents sur les deux pages Équipe

Chiffres réels du marché Libye (extraits le 17 août 2026 ; salle de contrôle figée au 16 août 20 h 34, dernière soirée active ; performance sur 10 → 16 août). Le taux est illustratif — 3,000 د.ل. par commande livrée, tasnim à 3,500 — et les paiements sont des exemples pour montrer chaque état (dont un solde négatif). Rien n'existe encore en base ni dans le code. v2–v4 : le taux et les interrupteurs (marché · par agent) se règlent dans Paramètres › Général, et l'agent voit son propre solde.

Points à valider (10)
  1. Salle de contrôle — le solde par agent entre dans la table (colonne « Solde »), pas dans une tuile : l'argent est par personne, les tuiles restent sur le travail bloqué.
  2. La barre-verdict gagne « N agents à payer (Σ) » et, seulement s'il y en a, « N solde négatif ».
  3. Le menu Action de chaque agent gagne « Enregistrer un paiement… ».
  4. Performance — 6ᵉ cellule « Commissions » dans la barre (acquis sur la période · livrées · versé).
  5. Chaque ligne du classement affiche « livrées N · +X » — la commission suit la livraison, l'agent doit voir le lien.
  6. Nouvelle carte « Commissions & paiements » (pleine largeur, sous Présence) : acquis / versé sur la période, solde depuis toujours, dernier paiement, bouton Payer, taux, export.
  7. Tiroir agent (commun aux deux pages) : section « Commission » + relevé + paiement. Modal de paiement : montant, date, mode, référence, note, et avertissement si le solde devient négatif.
  8. Paramètres › Général — nouvel onglet « Commissions » (super_admin) : taux du marché par commande livrée, date d'effet, exceptions par agent, historique. La carte Performance ne fait que pointer vers cet onglet.
  9. Interrupteurs — un interrupteur marché (« Commissions activées ») et un par agent, dans la même table que les taux ; couper = pause datée, jamais une suppression. Agent coupé : plus d'onglet côté agent, hors des totaux à payer, solde restant toujours payable.
  10. Vue agent — onglet « Mes commissions », volontairement minimal : un seul chiffre (À recevoir, depuis le dernier paiement), trois faits (ce mois · en cours · dernier paiement), et un historique par jour qui s'ouvre sur les commandes. Lecture seule ; arabe RTL pour la Libye.
