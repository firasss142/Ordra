Prospects · console · prototype manager v1 · Ordra

Même langage que l'écran agent (en-tête, puces de ton, lignes à bandeau, panneau à droite). Le métier change : ici on répartit, on regarde, on corrige, on pilote — on n'appelle pas.
Ce que le prototype décide (validé le 15 sept. 2026)
  • Quatre vues sur une seule route : Vue d'ensemble · Prospects · Campagnes · Équipe. La bannière rouge « sans agent » est le constat qui justifie la page : ~2 000 prospects, 99 % issus de campagnes, presque tous sans agent.
  • Répartition par règle (décision 33) : sélection d'un lot → agents cochés → règle « dernier agent qui a confirmé, sinon tour de rôle » → plafond par jour → aperçu qui reçoit combien → confirmer. Réassignation unitaire toujours possible.
  • Le manager supervise, modifie, réassigne, clôt. Il n'appelle pas et n'enregistre pas de résultat : les chiffres par agent restent honnêtes.
  • Super admin : un marché à la fois via le sélecteur de portée ; « Tous » donne une comparaison Tunisie / Libye sur la Vue d'ensemble, et les autres vues demandent de choisir un marché.
  • Créer à la main (téléphone d'abord, correspondance client en direct), importer un CSV (mappage + essai à blanc), modifier les champs, clore avec motif, rouvrir. Pas de suppression : l'historique est une piste d'audit.
  • Taux de conversion mesuré sur les appelés, jamais sur l'audience ; un agent sans appel aujourd'hui n'a pas de taux.
  • Téléphone : la Vue d'ensemble et l'Équipe se lisent ; répartir et construire une campagne demandent un grand écran.
